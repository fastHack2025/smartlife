# 📱 SmartLife — L’Assistant de Vie Intelligent

**SmartLife** est une application mobile tout-en-un développée par **Dave & Luce Solutions**, qui centralise :

- ✅ La gestion des finances personnelles et professionnelles
- ✅ Un assistant IA avec rappels, SMS, et planification
- ✅ Un module musical mettant en avant les artistes africains
- ✅ Un lecteur de livres populaires avec résumé et recommandations
- ✅ Une interface Apple-like, épurée et futuriste

---

## 🚀 Fonctionnalités

### 💰 Finances
- Ajout de revenus et dépenses
- Calcul de solde (vert/rouge)
- Historique visuel
- Prêt pour IA prédictive

### 🧠 Assistant IA
- Tâches + rappels avec date/heure
- Notification locale (Expo)
- SMS automatique via CinetPay (Cameroun)
- Extension future : IA auto-apprenante

### 🎵 Musique
- Lecture audio d’artistes africains
- Interface stylée avec illustration
- Préparation pour playlist intelligente

### 📚 Livres
- Lecture de résumés d’ouvrages populaires
- Contenu personnalisé
- Prévision IA + audio à venir

## 🛠️ Stack technique

| Technologie     | Usage                            |
|----------------|----------------------------------|
| Expo / React Native | Base de l’application mobile |
| TypeScript      | Typage fort                     |
| Tailwind / StyleSheet | Design stylé et rapide     |
| Expo AV         | Lecture audio                   |
| Expo Notifications | Rappels locaux push          |
| Twilio (en test) | Envoi SMS 🇺🇸                   |
| CinetPay        | SMS & Paiement 🇨🇲               |
| Cloudinary      | Stockage média (images/audio)   |
